## RMS value

For an AC voltage, the value that is converted into power in a resistor in the same way as a comparable DC voltage

[picture:725:e_effektivwert_230v:RMS value and peak value of the domestic mains voltage]

For sinusoidal voltages (without derivation)

$\hat{U} = U_{eff}\cdot \sqrt{2}$

---
[question:EB405]

<note>
* Solution on the next page
</note>
---
### Solution

$\hat{U} = U_{eff}\cdot \sqrt{2}$
$U_{eff} = \dfrac{\hat{U}}{\sqrt{2}}$
$U_{eff} = \dfrac{\qty{1}{\volt}}{1.41} \approx \qty{0.7}{\volt}$

### Solution

$\hat{U} = U_{eff}\cdot \sqrt{2}$
$\hat{U} = \qty{12}{\volt}\cdot 1.41 \approx \qty{17}{\volt}$

$U_{SS} = 2\cdot \hat{U}$
$U_{SS} = 2\cdot \qty{17}{\volt} = \qty{34}{\volt}$
