## Phase-shift keying (PSK)

* Digital modulation method for data transmission
* The symbols are represented by different phases of a carrier
* With ideal PSK, the amplitude and frequency of the carrier stay the same
* When the symbol changes, the phase can change

--- style="font-size: smaller;"

## PSK in the time domain

<left>
[picture:705:a_psk:Phase-shift keying]
</left>
<right>
* The amplitude stays constant
* The information is carried in the *phase*
* When the signal changes between two symbols, the phase can change abruptly
* If the same symbol is transmitted again, the phase also stays the same
</right>

--- style="font-size: smaller;"

## Binary phase-shift keying (BPSK)

<left>
[picture:1101:a_psk_mapping:BPSK in the constellation diagram]
</left>
<right>
* Two different phases
* Two possible symbols
* This allows $\num{1}$ bit per symbol to be transmitted
* Example: $\qty{0}{\degree}$ → $0$ and $\qty{180}{\degree}$ → $1$
* The two signal points lie opposite each other in the constellation diagram
</right>

<note>
The simplest form of phase-shift keying is BPSK. The two possible symbols have the same amplitude, but their phases differ by 180 degrees.

Side note: mathematically, BPSK can also be generated by multiplying the carrier by +1 or -1, depending on the bit value. Multiplying by -1 corresponds to a phase shift of 180 degrees:

$-\sin(\omega t)=\sin(\omega t+\qty{180}{\degree})$

The choice of 0 degrees and 180 degrees is not compulsory. 90 degrees and 270 degrees, for example, would be just as possible.
</note>

## More phases – more symbols

* With more phases, more different symbols can be represented
* This allows several bits to be combined into one symbol

<fragment>
* *BPSK*: $\num{2}$ symbols → $\num{1}$ bit per symbol
* *QPSK*: $\num{4}$ symbols → $\num{2}$ bits per symbol
* *8-PSK*: $\num{8}$ symbols → $\num{3}$ bits per symbol
</fragment>

## Quadrature phase-shift keying (QPSK)

* QPSK uses four different phases
* Four different symbols are therefore available
* Two bits at a time are combined into one symbol: $00$, $01$, $10$, $11$
* Each QPSK symbol therefore transmits $\num{2}$ bits

--- style="font-size: smaller;"

## QPSK in the constellation diagram

<left>
[picture:1059:a_qpsk:I/Q diagram for a QPSK mapping]
</left>
<right>
In this example:

* $11$ → $\qty{45}{\degree}$
* $01$ → $\qty{135}{\degree}$
* $00$ → $\qty{225}{\degree}$
* $10$ → $\qty{315}{\degree}$

<fragment>
* All signal points have the same amplitude
* The phases are each $\qty{90}{\degree}$ apart
* The four points lie on a circle
</fragment>
</right>

<note>
The assignment of the bit combinations to the individual phases is not fixed in principle. The transmitter and the receiver must, however, use the same mapping.

The mapping used here is also the one shown in the course text and in the following applet.
</note>

--- style="font-size: smaller;"

## Gray code in QPSK

<left>
[picture:1059:a_qpsk_gray:I/Q diagram for a QPSK mapping]
</left>
<right>
* Neighbouring symbols each differ in only *one bit*
* Such an assignment is called a *Gray code*

<fragment>
Example:

$11 \leftrightarrow 01 \leftrightarrow 00 \leftrightarrow 10$
</fragment>

<fragment>
If noise causes a neighbouring symbol to be detected by mistake, this often results in only a single bit error.
</fragment>
</right>

<note>
The mapping is chosen so that neighbouring points in the constellation diagram differ in only one bit.

From 11 to 01, for example, only the first bit changes. The same applies to the other neighbouring signal points, including 10 and 11.
</note>

<right>
### QPSK with noise
* Noise changes the amplitude and phase of the received signal
* The received values are scattered around the ideal QPSK symbols
* The receiver decides on the nearest symbol
* If a decision boundary is crossed, a symbol error occurs
</right>

<note>
The applet shows not only the ideal QPSK symbols but also the situation at the receiver.

The crosses mark the four ideal signal points. The small coloured dots represent noisy received values. Noise and other interference change both the amplitude and the phase of the received signal.

The coloured areas are the receiver's decision regions. The receiver assigns a received value to the nearest ideal symbol.

As long as a noisy point lies in the decision region of the symbol originally sent, the symbol is recognised correctly. If strong noise pushes the point across a decision boundary, a different symbol is recognised instead.

The button "Transmit again" transmits the same bit stream once more with new noise. This shows clearly that, although the same symbols are sent, the received values come out slightly different each time.

As the noise increases, so does the probability of symbol errors, and with them bit errors. Suitable channel coding can detect and correct many such errors.
</note>

## ASK and PSK in the constellation diagram

* In *ASK*, the symbols differ mainly in their amplitude
  * different distance from the origin
  * same phase
* In *PSK*, the symbols differ in their phase
  * same distance from the origin
  * different angle
* In PSK the signal points therefore lie on a circle if the amplitude is the same.
