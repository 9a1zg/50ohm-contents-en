## NTC thermistor
<left>
* An NTC thermistor is a temperature-dependent resistor
* Full name: negative temperature coefficient thermistor (*NTC*)
* Conducts electric current better at *high temperatures*
</left>

</right>
<note>
* Memory aid: the first arrow indicates the temperature, the second arrow the conductivity
