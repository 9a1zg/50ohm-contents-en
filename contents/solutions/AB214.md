A voltage converter converts an input voltage of $U_{\mathrm{in}} = \qty{5}{\volt}$ into an output voltage of $U_{\mathrm{out}} = \qty{12}{\volt}$. In doing so it draws an input current of $I_{\mathrm{in}} = \qty{3}{\ampere}$ and delivers an output current of $I_{\mathrm{out}} = \qty{1}{\ampere}$.

To calculate the efficiency, we first need the input and output power. These are calculated with

$ P = U \cdot I $

This gives the input power:

$ P_{\mathrm{in}} = U_{\mathrm{in}} \cdot I_{\mathrm{in}} = \qty{5}{\volt} \cdot \qty{3}{\ampere} = \qty{15}{\watt} $

The output power is:

$ P_{\mathrm{out}} = U_{\mathrm{out}} \cdot I_{\mathrm{out}} = \qty{12}{\volt} \cdot \qty{1}{\ampere} = \qty{12}{\watt} $

Now the efficiency can be calculated:

$ \eta = \frac{P_{\mathrm{out}}}{P_{\mathrm{in}}} = \frac{\qty{12}{\watt}}{\qty{15}{\watt}} = 0{.}8 $

To convert to a percentage, multiply by $\qty{100}{\percent}$:

$ \eta = 0{.}8 \cdot \qty{100}{\percent} = \qty{80}{\percent} $

So the voltage converter has an efficiency of $\qty{80}{\percent}$.
