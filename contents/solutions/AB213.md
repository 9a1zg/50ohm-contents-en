To calculate the powers we use the familiar formula

$ P = U \cdot I $

A voltage converter converts an input voltage of $U_{\mathrm{in}} = \qty{12}{\volt}$ into an output voltage of $U_{\mathrm{out}} = \qty{5}{\volt}$. In doing so it draws an input current of $I_{\mathrm{in}} = \qty{2}{\ampere}$ and delivers an output current of $I_{\mathrm{out}} = \qty{3}{\ampere}$.

First we calculate the input power:

$ P_{\mathrm{in}} = U_{\mathrm{in}} \cdot I_{\mathrm{in}} = \qty{12}{\volt} \cdot \qty{2}{\ampere} = \qty{24}{\watt} $

Then the output power:

$ P_{\mathrm{out}} = U_{\mathrm{out}} \cdot I_{\mathrm{out}} = \qty{5}{\volt} \cdot \qty{3}{\ampere} = \qty{15}{\watt} $

This gives the efficiency:

$ \eta = \frac{P_{\mathrm{out}}}{P_{\mathrm{in}}} = \frac{\qty{15}{\watt}}{\qty{24}{\watt}} = \num{0.625} $

To express it as a percentage, the value is multiplied by $\qty{100}{\percent}$:

$ \eta = \qty{62.5}{\percent} $

So the voltage converter has an efficiency of $\qty{62.5}{\percent}$.
