The phase shift is $\qty{0}{\degree}$. If the input voltage at the base rises, the emitter current also increases, and with it the voltage across the emitter resistor. The output voltage therefore follows the input voltage, so that the two signals are in phase.

As a reminder: 

| l: Property | X: Common-emitter circuit | X: Common-collector circuit |
| Phase shift | $\qty{180}{\degree}$ | $\qty{0}{\degree}$ |
| Voltage gain | $\num{100}\dots\num{300}$ | $\num{0.9}\dots\num{0.98}$ |
| Input impedance | high | high |
| Output impedance | high | low |
