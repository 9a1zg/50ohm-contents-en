# Given
Gain: $g_\text{Verstärkung} = \qty{10}{\dezibel}$  
Input power: $P = \qty{1}{\watt}$ (the output power of the transmitter is the input power of the power amplifier.)

# Solution
We calculate the input level with the $\unit{\dBW}$ formula from the formula sheet (levels, power and voltage levels):  
$ p_\text{Eingang} = 10 \cdot \log_{10}\left(\frac{P}{\qty{1}{\watt}}\right)\unit{\dBW} = \qty{0}{\dBW}$  
The output level then follows by simple addition:
$ p_\text{Ausgang} = p_\text{Eingang} + g_\text{Verstärkung} = \qty{0}{\dBW} + \qty{10}{\dB} = \qty{10}{\dBW}$

# Shortcut
The question can be solved even faster if you know that $\log\left(1\right) = 0$, so that $\qty{1}{\watt} \rightarrow \qty{0}{\dBW}$. The output level is then exactly the gain, at $\qty{10}{\dBW}$.
