# Given:
Inductance factor $A_\mathrm{L} = \qty{30}{\nano\henry}$  
(Target) inductance $L = \qty{12}{\micro\henry}$  
# Required:
Number of turns $N$  

# Solution
From the formula sheet we need the formula for the inductance of toroidal inductors:
$L = N^2 \cdot A_\mathrm{L}$
Solve it for $N$:
$L = N^2 \cdot A_\mathrm{L} \rightarrow N^2= \frac{L}{A_\mathrm{L}} \rightarrow N=\sqrt{\frac{L}{A_\mathrm{L}}}$
Substitute the given values:
$N=\sqrt{\frac{L}{A_\mathrm{L}}} = \sqrt{\frac{\qty{12}{\micro\henry}}{\qty{30}{\nano\henry}}} =  \sqrt{\frac{\qty{12}{\cdot10^{-6}\henry}}{\qty{30}{\cdot10^{-9}\henry}}} =  \sqrt{\frac{12}{30\cdot10^{-3}}} = \sqrt{\frac{12000}{30}} = \sqrt{\frac{1200}{3}} = \sqrt{400} = 20 $
