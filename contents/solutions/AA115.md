# Given
$f = \qty{435}{\mega\hertz}$

# Solution 
$\unit{ppm}$ stands for *parts per million*, i.e. $1$ per $10^6$.  

$\qty{435}{\mega\hertz} \cdot \frac{1}{10^6} = \frac{435 \cdot \qty{\cancel{10^6}}{\hertz}}{\cancel{10^6}} = \qty{435}{\hertz}$

# Shortcut
$\unit{ppm}$ ($\frac{1}{10^6}$) fits very well with the frequency given in $\unit{\mega\hertz}$ ($\qty{10^6}{\hertz}$). So without much calculation you know: one $\unit{ppm}$ of $\qty{435}{\mega\hertz}$ is $\qty{435}{\hertz}$.
