For power matching, the load impedance must be exactly as large as the output impedance of the signal source.

The following holds:

$Z_\mathrm{L} = Z_\mathrm{i}$

The signal source has an output impedance of $\qty{50}{\ohm}$, so the load impedance must also have the value

$Z_\mathrm{L} = \qty{50}{\ohm}$
